# DROPZERO Privacy Policy & Engineering Guarantees

- **Zero Accounts**: No login, registration, OAuth, or identity server exists.
- **Zero File Storage**: The signaling server holds pairing codes and session metadata solely in RAM for up to 10 minutes.
- **Zero Analytics / Ads**: Zero third-party trackers, pixels, or telemetry beacons.
- **Local-Only Ledger**: History, preferences, recovery checkpoints, and optional remembered peer fingerprints live strictly inside the user's local IndexedDB database (`dropzero_local_v1`) and can be erased in one click from `/settings`.
